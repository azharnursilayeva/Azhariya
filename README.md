# Azhariya — сайт женской одежды

Статичный адаптивный сайт из трёх экранов: главная, коллекция, о бренде и контакты. Без сборки и зависимостей: HTML, CSS и JavaScript.

## Файлы

- `index.html` — разметка страницы
- `styles.css` — стили и адаптивность (десктоп, планшет, телефон)
- `script.js` — каталог и фильтры, мобильное меню, вход администратора и редактор данных

## Запуск на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в корень все файлы из этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Локально можно просто открыть `index.html` в браузере.

## Как заменить фотографии

Сейчас вместо фото стоят подписанные заглушки. Создайте папку `images/` и положите туда снимки (лучше WebP или JPG, до 300–400 КБ каждый).

- Главный экран и «О бренде»: в `index.html` замените блок `<div class="ph hero-p">` (и `ph tone3 story-p`) на `<div class="ph hero-p"><img src="images/hero.jpg" alt="Описание фото"></div>`.
- Товары: фото загружаются прямо в редакторе администратора. Чтобы фото видели все посетители, положите файл в `images/` и укажите путь в поле `img` в `DEFAULTS.products` в `script.js`.

## Администратор

Кнопка «Вход для администратора» находится в подвале. Пароль задаётся в `script.js`, в переменной `ADMIN_PIN` (6 цифр).

После входа открывается редактор: бренд, локация, телефон, Instagram, тексты экранов, каталог (добавление, удаление, порядок, название, цена, категория и фото товаров).

**Важно:**

- Пароль лежит в открытом коде и виден всем, кто откроет страницу. Если репозиторий публичный, пароль публичный. Это защита от случайных нажатий, а не от посторонних.
- Правки сохраняются в `localStorage` браузера, где их внесли. Другие посетители их не увидят. Чтобы изменения видели все, поменяйте значения в `DEFAULTS` в `script.js` или подключите серверную часть.
- Для настоящей админки нужны вход и хранение данных на сервере (например, Firebase, Supabase или собственный бэкенд).

## Что заменить на реальные данные

Телефон, Instagram, цены и ассортимент в проекте демонстрационные. Укажите настоящие данные через редактор или прямо в `DEFAULTS` в `script.js`.
